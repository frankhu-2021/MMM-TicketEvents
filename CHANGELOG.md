# Changelog

## [1.0.0] - 2026-05-29

Initial release:
- Event display using Ticketmaster Discovery API
- Carousel-style event rotation with fade transitions
- Configurable location (city or lat/lon with radius)
- Filter by classification (Music, Sports, Arts, Theatre, Family)
- Event images with placeholder gradient fallbacks
- Formatted date/time with timezone awareness
- Venue and location display
- Price range display
- Genre/segment badges
- Clickable "Get tickets" link
- Error handling with user-friendly messages
- Loading state display
- Configurable update and rotation intervals
